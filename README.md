Este código es básicamente la estructura de un juego de 3 jugadores. Cada uno puede atacar a otro jugador o pasar su turno. En la pantalla aparecen los tres jugadores con sus porcentajes, los botones para atacar y pasar y una opción para elegir a quién quieres atacar. También aparece si cada jugador sigue vivo o ha sido eliminado. Arriba está el botón START para empezar el juego. Luego, con el CSS se le da forma y color a la página y con JavaScript se consigue que funcionen los ataques, los turnos y todo lo demás.
Este código es el que hace funcionar el juego. Primero, todos los botones están desactivados y, al pulsar START, empieza la partida. Los jugadores van pasando los turnos y pueden atacar o pasar. Los ataques tienen una probabilidad de salir bien según el porcentaje de cada jugador. Si un ataque funciona, el jugador atacado queda eliminado. Cuando solo queda uno vivo, el juego termina y se desactivan todos los botones.
